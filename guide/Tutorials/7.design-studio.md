# Archivist Plus Design Studio

## Architecture summary

The Design Studio now uses one shared message tree so the same data can power the visual builder, nested block layout, live preview, validation, templates, draft saving, and JSON import/export.

### What this version includes

- **Two message types**: classic embed mode and components message mode.
- **Three-panel builder**: blocks on the left, layout in the middle, settings on the right.
- **Beginner-friendly wording**: labels, helper notes, and checks use simple language.
- **Nested building**: boxes, rows, and button rows can now hold child blocks in the canvas.
- **Reusable data model**: every message is stored as a document with blocks, settings, and optional children.
- **Instant preview**: the preview updates whenever a block changes.
- **Helpful checks**: short validation notes guide the user without sounding harsh.
- **Portable editing**: templates, local saved drafts, and JSON import/export are all included.
- **Mobile-first behavior**: the sidebars collapse into panel tabs on smaller screens.

### Internal structure

- **Document level**: stores the message type, name, summary, and top-level blocks.
- **Block level**: every block has an id, type, label, helper copy, settings, and optional child blocks.
- **Tree helpers**: selection, movement, duplication, insertion, and removal all work on the same block path system.
- **Derived views**: preview output and validation messages are computed from the same source of truth.
- **History layer**: undo and redo use lightweight snapshots so the builder stays easy to extend.

### What should come next

- true drag and drop sorting
- richer preview styling for every Discord component state
- server-side template storage and real publish actions
- more advanced layout rules hidden behind an advanced mode
